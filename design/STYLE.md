# 多角的占い診断 — 画像生成の共通スタイル指定

すべての生成プロンプトの冒頭に、この【共通スタイル】を貼り付ける。
生成エンジン: Codex CLI の画像生成機能（ChatGPT課金枠内・追加課金ゼロ）

## 【共通スタイル】

- 対象: 40〜60代の日本人女性。美容講座の受講生限定サイト
- トーン: 上品・ロマンティック・静かな高級感。占いの怪しさは出さない
- 画風: 写真ではなく、繊細で上品なイラストレーション（水彩とデジタルの中間）
- 人物: 顔は描かない（後ろ姿・シルエット・手元のみ可）

### 配色（厳守）
| 役割 | 色 |
|---|---|
| ベース | ピーチピンク #fef0ee / ベビーピンク #fbe6eb / ピンクラベンダー #f4e3ee |
| アクセント | ローズ #d56a7e / ワインレッド #7a2e44 |
| 差し色 | くすみゴールド #c89b6a（細線・粒子として少量） |
| ごく淡く | ラベンダー #b9a3d4 |

### 禁止事項（全画像共通）
- 文字・ロゴ・タイポグラフィを一切入れない
- タロットカード・水晶玉・ホロスコープ盤など直接的な占具を描かない
- 彩度の高い色、原色、黒の締め色を使わない
- 人物の顔、目、表情を描かない

## 生成コマンド

```bash
cd "/Users/tanakamasamichi/Desktop/AIフォルダまとめ/新占いサイト"
codex exec --skip-git-repo-check --sandbox workspace-write "$(cat design/prompts/<名前>.txt)"
```

一括生成（優先度順・枠を見ながら分割推奨）:
```bash
bash design/generate.sh
```


## 画面側のデザインシステム（v49〜・`assets/css/refined.css`）

| 役割 | 指定 |
|---|---|
| 見出し | Shippori Mincho 500〜600 / 字間 0.08〜0.16em / 色 #742b41 |
| 本文 | Zen Kaku Gothic New 400 / 16px / 行間 1.95 / 色 #38292f |
| 英字ラベル・番号 | Cormorant Garamond（italic 可）/ 字間 0.3em / 色 #9c7a4a |
| 地色 | #fbf6f2 → #f7eeec の淡いグラデーション＋紙の粒子（opacity .045） |
| カード | #fff / 1px #eadfdb / 角丸 18〜22px / 影 0 10px 30px rgba(84,46,58,.07) |
| 締め色 | ワインレッド #742b41（ボタンは #7c2f47→#5a2034） |
| 細線・装飾 | 金 #c3a274（枠は rgba(195,162,116,.5) 前後） |
| 禁止 | 手書き風フォント、点線・破線の枠、絵文字アイコン、彩度の高い色、黒 |

生成画像は上記の配色に合わせ、CSS側では「画像 → グラデーション」の順に重ねる
（画像が無くても成立させる）。画像は生成後に `sips` で JPEG 化・長辺 1600px 以内に縮小する。
