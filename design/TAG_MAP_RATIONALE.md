# TAG_MAP_RATIONALE — 占術結果→特徴タグ写像の根拠

作成: 2026-09-13 / 作成者: Claude（一般知識に基づく）/ **状態: 占術専門家による検証待ち**

統合分析の中核は `assets/js/content.js` の `TAG_MAP` です。各占術の値（星座・干・数など）に
16種の特徴タグを最大3つ割り当てています。**この対応表は Claude が作成したもので、
各占術の流派・一次資料との突合はまだ行っていません。** 検証者が読めるよう、方針と根拠を残します。

## 16タグ
independence 自分で決めたい力 / cooperation 人と組む力 / action 動き出す力 / caution 見極める力 /
sensitivity 感じ取る力 / logic 筋道を立てる力 / creativity 独自の視点 / stability 積み上げる力 /
challenge 新しさに向かう力 / perfectionism 基準の高さ / expression 伝える力 / reserve 内側で深める力 /
nurturing 育てる力 / competition 勝ちにいく力 / adaptability 合わせる力 / persistence 貫く力

## 方針
1. 各占術には「担当する視点」を1つ決め、同じことを全占術に言わせない（`TAG_SOURCES.role`）
2. 並び順＝主要度（1位1.0／2位0.75／3位0.55 の重み）
3. 情報量の多い占術ほど重みを大きく（時刻を要する精密占術3、簡易分類1）
4. 偶然の一致率は写像表の構造から自動算出するため、タグの出現回数の偏りは判定段階で補正される。
   ただし最上位タグの集中を避けるため、第3位の偏在は手で調整した（2026-09-13：伝える力を6箇所差し替え）

## 既知の課題
- 16タグの一部が近い（貫く力/積み上げる力、動き出す力/新しさに向かう力、感じ取る力/育てる力）
- 各占術内での値の粒度が違う（12値／10値／9値／6値）ため、6値の占術は1値あたりの寄与が大きい
