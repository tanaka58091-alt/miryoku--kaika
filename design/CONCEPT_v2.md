# 多角的占い診断 v2.0 ― コンセプト設計書

作成: 2026-09-30 / 対象: `index.html`（新版）。旧版は `legacy.html` にそのまま残しています。

---

## 1. なぜ作り直したか

旧版（v1〜v76）は、20種類の占術がそれぞれ「あなたは○○」と語る構造でした。改善を重ねても、次の3点が根本的に解消できませんでした。

1. **答えが20個ある**。読み終えても「結局わたしは何者か」が一言で残らない
2. **文章が誰にでも当てはまる**。定型文の組み合わせで、「なんで分かるの」という驚きが生まれにくい
3. **美容講座の道具なのに、美容との接続が弱い**

## 2. コンセプト

> **あなたは、どの季節の、どんな自然？**

先天性の核を**ひとつのタイプ名**で渡し、それを美容と日常の言葉に訳します。

- **生まれた日の「干」10種 × 生まれた「季節」4種 ＝ 40タイプ**
- 四柱推命で本質を表す日干を、伝統的な自然のたとえ（大樹・花・太陽・灯火・山・大地・鋼・宝石・海・雨）で表す
- 同じ日干でも生まれた季節で出方が変わるという、四柱推命の調候（ちょうこう）の考え方を、「春の灯火」「冬の大樹」という名前にする
- 季節は暦の上の区切り（立春・立夏・立秋・立冬）で決める

### 満足度を高める設計の原則

| 原則 | 具体 |
|---|---|
| 一言で言える自分 | 「私は春の灯火」。受講生同士の話題になる |
| 結論は1箇所だけ | タイプカードが結論。他の章は角度を変えて深めるだけ |
| 行動の具体で書く | 「大勢を照らすより、目の前のひとりを温める人」のように |
| 影もやさしく | 「無理をすると、こうなりやすい」＋理由＋戻し方をセットで |
| 使える | 似合う質感・色の方向・香り・所作・魅力が出る瞬間 |
| 人と見せ合える | 相性、40タイプ一覧で家族や友人も調べられる |
| また来る理由 | 今年・今月の流れは月ごとに変わる |
| 美しいカード | タイプごとの水彩イラスト（40枚）。スクリーンショットで保存できる |

## 3. 多角的＝占術の数ではなく、視点の数

| 視点 | 占術 | 使う値 |
|---|---|---|
| 生まれ持った本質（先天的な性格） | 四柱推命 | 日干×季節（40タイプ） |
| 表の顔 | 西洋占星術 | 太陽星座 |
| 心の内側 | 西洋占星術 | 月星座 |
| 愛と美の感性 | 西洋占星術 | 金星星座 |
| 人生のテーマ | 数秘術 | ライフパス |
| 今年と今月の流れ | 四柱推命 | 流年・流月の通変星 |
| 相性 | 四柱推命 | 日干どうしの五行（相生・相剋・比和・干合） |

3つの伝統的な占術だけを使い、それぞれ得意な視点に当てています。特定の商標（動物占い・六星占術など）には依存しません。

## 4. 画面構成

1. **合言葉**（旧版と共通。一度通れば新旧どちらも省略）
2. **トップ**：「あなたは、どの季節の、どんな自然？」／40タイプの決まり方／6つの角度
3. **入力**：生年月日（必須）、生まれた時刻・お名前（任意）。約30秒
4. **演出**：「あなたの季節を読んでいます」→「春の気配がします…」（約2秒）
5. **結果**：タイプカード → 6つの角度の一覧 → 7つの章
   - 01 生まれ持った本質（先天的な性格・強み・季節の贈り物・無理をしたときの出方）
   - 02 表の顔と、心の内側
   - 03 あなたの美しさ
   - 04 愛し方と、活きる場所
   - 05 人生のテーマ
   - 06 疲れたときは
   - 07 今の流れ
6. **手相**：手のひらを1枚撮るだけ。手の形・指・4本の線を読み取り、写真に線を描いて結果を見せる。左右両方を撮ると、違いを読む（図を見て選ぶ方式も予備で残す）
7. **人相**：自撮りを1枚撮るだけ。顔立ちのタイプ（花・鳥・風・月）、三停、パーツごとの読みと「ひとことアドバイス」
8. **相性**：お相手の生年月日から、ふたりの関係のかたち
9. **タイプ図鑑**：大切な人の生年月日を入れると、その人のタイプが分かる。10×4 の表に「あなた」と調べた人のしるし。そのまま相性へ
10. **よくあるご質問**

結果は生まれた季節の色（春＝桜・若草／夏＝水色・緑／秋＝琥珀・朱／冬＝雪白・藍）で染まります。

### 手相・人相の設計（v2.2：写真1枚で）

- **撮るだけ。** 図を見比べて選ぶ方式は「誰もやらない」という声を受け、写真1枚で読む方式を基本にした（図で選ぶ方式は予備の入口として残す）
- 写真から点を読み取るのは MediaPipe（Google・無償・Apache 2.0）。**サイトの中に同梱して、端末の中だけで動かす。** 利用統計の送信は無効化し、CSP で外部通信も止めている。写真は保存も送信もしない
- 手相：手の形（火・地・風・水）＋指＋4本の線。線は手相の見方の順（生命線 → 知能線 → 感情線 → 運命線）にたどり、濃さを3段階で判定。**読み取れなかった線は断定しない**。結果は本人の写真に線を描いて見せる（納得感と誠実さ）
- 人相：顔の比率から、輪郭・三停・眉・目・鼻・口元・あごを読み、顔立ちのタイプ「花・鳥・風・月」を出す。美容講座の受講生向けに、パーツごとの「ひとことアドバイス」（メイク・髪・表情）と、タイプ別の装いのヒントをつける
- 手相・人相は生年月日の40タイプとは独立した占い。3つのうち2つ以上そろうと **総合鑑定（#total）** で重ねて読む

### 一人ひとりのオーダーメイドにする仕組み（v2.3）

- **総合鑑定**：本質（日干）・生き方（手の形）・印象（顔立ち）から、その人だけの一文と「内面と印象」「本質と生き方（五行）」「これからの運の流れ」を組み立てる（`shiki-total.js`、文は `shiki-data.js` の `TOTAL`）
- **あなたらしさの核**：平均からいちばん離れた特徴を最初に語る。人相は章の順番もその人ごとに変わる
- **語りかけ**：「あなたの〜は」の文体。お名前があれば「〇〇さん」
- **あなたの実測**：測った値と平均との違いを見せ、「本当に自分を測った」納得感をつくる

## 5. 正確さの扱い

- 日干・季節・星座はすべて計算で確定（自動テスト：`node tests/shiki.test.js` 42件、`node tests/vision.test.js` 47件（写真の読み取り）、`node tests/total.test.js` 27件（総合鑑定）、`node tests/calc.test.js` 51件）
- 生まれた時刻が分からない場合は正午で計算し、**その日のうちに値が変わる場合は画面で知らせる**
  - 季節の変わり目の日：「21時ごろより前なら冬の海、後なら春の海」
  - 月星座が切り替わる日：「14時ごろより前なら山羊座」
- 23時台生まれは翌日の日干（夜子時）
- 1万人の試算で、40タイプはすべて1.5〜3.5%の範囲に収まる（均等なら2.5%）

## 6. 講師に監修してほしいこと（重要）

**解説文は Claude が下書きしたものです。** 占いの計算は伝統的な方法で確定していますが、文章の響き方は受講生を知る講師の言葉に整えることで、満足度が大きく上がります。優先順位の高い順に：

1. **日干10種の本文**（`assets/js/shiki-data.js` の `STEMS`）：本質・強み3つ・無理をしたときの出方・美しさ
2. **40タイプの一言と季節の贈り物**（同 `TYPES`）
3. 星座・数秘・今の流れ・相性の短文
4. 手相・人相の解説とヒント（同 `PALM_AUTO`・`FACE_AUTO`。図で選ぶ方式は `PALM`・`FACE`）

文章だけを直す場合は `shiki-data.js` の該当箇所の文字を書き換えるだけで反映されます（画面側の修正は不要）。
